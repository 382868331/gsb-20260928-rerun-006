# 人工医学影像研究工作站

当前迭代覆盖影像组导入、轴/冠/矢三视图联动、基于物理坐标的空间测距，以及浏览状态与测量保存恢复。全部样本均为算法生成的研究模体，不包含、也不生成诊断结论。

## 数据身份与空间约定

- 每个影像组使用稳定 `image_id`，后续分割和配准直接沿用该身份。
- `identity.json` 保存 IJK→XYZ 的 4×4 仿射矩阵，矩阵由方向矩阵、体素间距和原点组成。
- 三视图位置共享同一个整数 IJK 点；切换方向不会改变空间位置。
- 测距先经仿射矩阵转换到 XYZ 毫米坐标，再计算欧氏距离，避免不等间距导致偏差。
- 影像级方向矩阵必须为带符号轴排列且正交；层片缺号、尺寸不符会拒绝导入，单层方向可缺省，若提供则必须与影像级方向一致。

## 启动

```bash
.venv/bin/python -m uvicorn backend.main:app --reload --port 8000
cd frontend
npm run dev
```

打开 Vite 输出的本地地址，点击“导入内置翻转模体”。该模体包含：

- 中央空腔；
- IJK 到 XYZ 的 X、Z 方向翻转；
- `1.5 × 2.0 × 2.5 mm` 的不等体素间距。

## 保存与恢复

在“会话”中输入编号并保存，会把当前影像身份、三视图 IJK 位置和测量记录写入 `data/sessions/`。恢复时重新校验影像身份，避免把状态错误套用到其他影像。
