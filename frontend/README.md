# 医学影像研究工作站

可运行的影像处理与切片页面：打开体数据、轴向/冠状/矢状三视图联动浏览、三维距离测量与持久化。

## 运行

```bash
cd frontend
npm install      # 依赖已在离线 node_modules 中时可跳过
npm run dev      # 启动后打开终端提示的本地地址
npm test         # vitest：24 个用例
npm run build    # tsc 类型检查 + 生产构建
```

## 主线功能

- **体数据打开**：内置人工体模（24×20×16），椭球亮壳包暗空腔、高亮标记点；层序翻转（k 轴朝足侧，方向行列式 −1）、不等间距（1.2/0.8/2.5 mm）。工具栏可预览“乱序”序列，并一键载入“缺片”“方向冲突”“混合冲突”序列验证校验。
- **三视图联动**：任意视图点击即按患者坐标定位，另两个视图的切片与十字线同步跳到同一点；滚轮或滑块切层。标记点在轴向/冠状/矢状视图反算回的患者坐标完全一致（见核心测试）。
- **测量保存**：测量模式下在视图上点两个端点，距离按患者坐标计算（含三个方向不等间距与方向翻转），不是数组下标距离；结果列在右侧面板，可删除。
- **空间解释**：`ijkToWorld/worldToIjk` 使用 origin + direction·(ijk*spacing)，视图按物理尺寸（mm）等比缩放并显示解剖方位标签（翻转层序时轴向视图显示足侧 I）。
- **导入前空间排列预览**（`src/core/importAnalysis.ts` + `ImportPreview.tsx`）：导入序列先分析、弹预览，上排按原始提供顺序、下排按空间位置展示每一张切片，并列出位置 t、相邻间距与方向关系；用户确认后才替换当前数据，取消则保留已打开影像与测量。
- **方向翻转 vs 位置变化**：整批层序严格反向（提供顺序与空间顺序相反）识别为合法“层序翻转”，仅按位置反向重排、不改动像素；部分帧前后错位识别为“乱序”警告，同样按位置重排；单帧法线反向（从对侧扫描）判为“方向翻转冲突”，绝不静默翻转像素掩盖冲突。
- **完整性校验**（`src/core/series.ts` + `importAnalysis.ts`）：尺寸/像素数不一致、间距非法或不一致、方向不垂直/不共栅格、方向相反、重复位置、栅格不等距、缺片都会分别逐条给出原因；乱序、重复位置、缺片、相反方向混在同一批时分类列出。
- **不覆盖保护**：分析未通过或用户未确认时，当前影像、浏览位置与测量保持不变。
- **重开恢复**：浏览切片、定位点、测量以稳定数据集 id 为键存入 `localStorage`，同时保存原始帧来源（含 sourceName、方位、位置、像素）；重开工程（刷新页面）时按原帧重新分析、组卷，恢复影像、导入判定（翻转/乱序）、原始来源与测量，且数据集 id 与空间测量保持不变。

## 代码结构

- `src/core/types.ts` 类型与错误类型
- `src/core/geometry.ts` 向量/方向矩阵、IJK↔患者坐标、方位标签
- `src/core/series.ts` 帧序列完整性校验与组卷
- `src/core/importAnalysis.ts` 导入前空间排列分析（顺序/间距/方向关系，冲突分类）
- `src/core/phantom.ts` 人工体模、帧序列化、缺片/方向冲突注入
- `src/components/ImportPreview.tsx` 导入前空间排列预览对话框
- `src/core/slices.ts` 三视图切片提取与平面↔患者坐标
- `src/state/store.ts` zustand 状态与 localStorage 持久化
- `src/components/MprView.tsx` 单视图 Canvas（窗宽窗位、十字线、测量叠显、方位标签）
