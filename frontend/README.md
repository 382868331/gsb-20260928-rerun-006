# 医学影像研究工作站

可运行的影像处理与切片页面：打开体数据、轴向/冠状/矢状三视图联动浏览、三维距离测量与持久化。

## 运行

```bash
cd frontend
npm install      # 依赖已在离线 node_modules 中时可跳过
npm run dev      # 启动后打开终端提示的本地地址
npm test         # vitest：48 个用例
npm run build    # tsc 类型检查 + 生产构建
```

## 主线功能

- **体数据打开**：内置人工体模（24×20×16），椭球亮壳包暗空腔、高亮标记点；层序翻转（k 轴朝足侧，方向行列式 −1）、不等间距（1.2/0.8/2.5 mm）。工具栏可预览“乱序”序列，并一键载入“缺片”“方向冲突”“混合冲突”序列验证校验。
- **三视图联动**：任意视图点击即按患者坐标定位，另两个视图的切片与十字线同步跳到同一点；滚轮或滑块切层。标记点在轴向/冠状/矢状视图反算回的患者坐标完全一致（见核心测试）。
- **测量保存**：测量模式下在视图上点两个端点，距离按患者坐标计算（含三个方向不等间距与方向翻转），不是数组下标距离；结果列在右侧面板，可删除。
- **空间解释**：`ijkToWorld/worldToIjk` 使用 origin + direction·(ijk*spacing)，视图按物理尺寸（mm）等比缩放并显示解剖方位标签（翻转层序时轴向视图显示足侧 I）。
- **导入前空间排列预览**（`src/core/importAnalysis.ts` + `ImportPreview.tsx`）：导入序列先分析、弹预览，上排按原始提供顺序、下排按空间位置展示每一张切片，并列出位置 t、相邻间距与方向关系；用户确认后才替换当前数据，取消则保留已打开影像与测量。
- **方向翻转 vs 位置变化**：整批层序严格反向（提供顺序与空间顺序相反）识别为合法“层序翻转”，仅按位置反向重排、不改动像素；部分帧前后错位识别为“乱序”警告，同样按位置重排；单帧法线反向（从对侧扫描）判为“方向翻转冲突”，绝不静默翻转像素掩盖冲突。
- **完整性校验**（`src/core/series.ts` + `importAnalysis.ts`）：尺寸/像素数不一致、间距非法或不一致、方向不垂直/不共栅格、方向相反、重复位置、栅格不等距都会分别逐条给出原因；乱序、重复位置、缺片、相反方向混在同一批时分类列出。缺片不再阻止导入：缺片层以空缺槽位（NaN 占位层）保留在体数据中，轴向视图以斜纹标示“缺片”，等待同一批采集的补片。
- **补片与替换片**（`src/core/patch.ts` + `PatchPreview.tsx`）：空间排列确认后，可继续接收同一批采集的补片/替换片。预览在现有体数据旁逐帧列出：补片（正好落入缺片槽位）、新增位置（沿栅格扩展范围）、重复位置（替换候选，标注内容是否与现片不同）、位置冲突（不在栅格上）、方向/尺寸冲突；用户逐帧勾选采用后才生效。缺片槽位只被同位置补片填补，其它位置的切片不会顶替缺片。
- **更新前后比较与撤销**：替换候选在预览中并排显示更新前后截面；模拟结果预先列出内容变化层与将进入待复核的测量（含其依据的采集版本）。拒绝更新不改动任何数据；确认后仍可通过“撤销更新”回到更新前的体数据与测量状态。
- **测量复核状态**：测量记录患者坐标与所依据的采集版本。补片/替换片改变了某层可见内容时，端点落在该层的测量进入“待复核”（可逐条复核确认），未受影响位置的测量保持原确认；每条测量同时标示更新后是否仍落在有效影像范围内（有效 / 超出范围 / 位于缺片层）。
- **跨层测量依据**：每条测量保存实际跨越的层号集合，以及每层的来源帧、所属采集和像素内容指纹。名称相同或层号相同不会被视为同一依据；只有测量经过的每层内容仍被合并版采用时，已确认测量才能直接沿用，缺片或内容替换会让该测量进入待复核。
- **双审阅三方合并**：可分别保存审阅 A/B 两个独立版本，再生成独立合并采集版本，两份来源审阅不会被覆盖。合并预览逐层区分“共同来源一致决定”“独立决定一致”“同一来源重复导入”“同位置不同像素”“仅一方补入”“双方均缺片”和方向/尺寸/位置争议；同位置不同内容必须显式选择，未解决层在合并版中保持“不确定”，不会因导入顺序自动获胜。逐层决定即时持久化：关闭预览或页面后重开可继续，可单独撤回某一层另选而不清空其他已确认层；撤回后依赖该层像素的测量按每层内容指纹重新核对（含两端未变、中间依据变化的测量），不凭层名或端点认定可沿用。
- **合并撤回与重开比较**：合并版记录两份来源版本，可撤回合并并恢复来源版本的缺片、跨层测量状态与采用来源；保存重开后，每条有效测量仍可列出其实际使用的切片集合。
- **层间一致性辅助审阅**（`src/core/consistency.ts` + 合并预览面板）：逐层决定后，系统按相邻层的几何位置（患者坐标物理间距，非层号）、前景掩码边界 IoU 与可用像素比例计算可疑跳变区间，并区分真实来源差异、缺层与空间信息不兼容三类；诊断仅提示，绝不凭视觉平滑自动替换任何决定。审阅者可在可疑层建立局部候选调整，比较切换前后的连续性（邻层掩码 IoU）与保留原选择的代价（推翻已确认决定数、依据该层的测量条数）；只有明确批准的层才进入逐层选择并随合并生效。修改一层仅让其直接邻域（±1 层）的诊断过期重算，远处已确认层保持原诊断对象与依据。检验使用无患者标识的人工体模：连续渐变形（细层间距）、突变台形（宽层间距）、缺层序列与不等间距。
- **到达顺序无关**：补片分析与应用只按空间位置落槽，同一批补片无论以什么顺序到达，最终排列与体数据内容完全一致（有核心测试覆盖）。
- **采用决定持久化**：每层切片的采用清单（来源帧、来自哪版采集）、每次候选的采用/拒绝决定、采集批次历史都随工程保存；重开后可回查每张切片的采用决定与每条测量所依据的采集版本，数据集 id 在补片前后保持稳定。
- **不覆盖保护**：分析未通过或用户未确认时，当前影像、浏览位置与测量保持不变。
- **重开恢复**：浏览切片、定位点、测量以稳定数据集 id 为键存入 `localStorage`，同时保存原始帧来源（含 sourceName、方位、位置、像素、所属采集批次）与切片采用清单；重开工程（刷新页面）时按原帧重新分析、组卷，恢复影像、导入判定（翻转/乱序/缺片槽位）、原始来源、采集批次历史、采用决定与测量，且数据集 id 与空间测量保持不变。

## 代码结构

- `src/core/types.ts` 类型与错误类型
- `src/core/geometry.ts` 向量/方向矩阵、IJK↔患者坐标、方位标签
- `src/core/series.ts` 帧序列完整性校验与组卷（含缺片槽位组卷 `buildVolumeFromSlots`）
- `src/core/importAnalysis.ts` 导入前空间排列分析（顺序/间距/方向关系，冲突分类）
- `src/core/patch.ts` 补片/替换片分析与应用（落槽分类、变化层计算、测量有效范围判定）
- `src/core/consistency.ts` 层间一致性诊断（可疑跳变区间、候选调整代价比较、邻域失效）
- `src/core/phantom.ts` 人工体模、帧序列化、缺片/方向冲突注入、补片批次生成
- `src/components/ImportPreview.tsx` 导入前空间排列预览对话框
- `src/components/PatchPreview.tsx` 补片/替换片预览（逐帧采用、更新前后截面比较、测量影响模拟）
- `src/core/slices.ts` 三视图切片提取与平面↔患者坐标
- `src/state/store.ts` zustand 状态与 localStorage 持久化
- `src/components/MprView.tsx` 单视图 Canvas（窗宽窗位、十字线、测量叠显、方位标签、缺片层标示）
