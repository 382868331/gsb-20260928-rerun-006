# 医学影像研究工作站

## 运行

```bash
cd frontend
npm run dev      # 开发服务器
npm run test     # 单元/集成测试
npm run build    # 类型检查 + 生产构建
```

## 主线功能

- **体数据打开**：由带方向信息的切片序列组装规则体数据（`src/imaging/geometry.ts` 的
  `buildVolume`）。列/行/层轴与翻转、体素间距都显式描述；缺片、尺寸不一致、像素数不符、
  非法间距、方向轴不构成 x/y/z 正交系时直接报错，不返回半成品，UI 保留原影像与测量。
- **三视图联动**：轴状/冠状/矢状位（`src/imaging/mpr.ts`）。画布方向固定，体数据方向翻转
  只作用于下标映射；十字光标即同一物理点在三个视图中的位置。点击任一视图跳转光标，滚轮翻层。
- **测量**：所有测量点保存为**物理坐标（毫米）**，距离按
  `sqrt(dx^2+dy^2+dz^2)` 与各轴 spacing 计算，绝不使用数组下标差。
  测量按体数据签名关联；换影像不会覆盖或错误迁移旧测量，重新打开原影像后恢复可见。
- **工程重开**：zustand persist 将体模规格、光标体素下标、测量存入 localStorage，
  刷新后确定性重建体数据（id 由几何+内容签名决定），恢复原浏览位置和全部测量。

## 人工影像

`src/imaging/phantom.ts` 生成 24×20×16 体模：间距 1.0/1.5/2.5 mm（不等间距），
y、z 轴方向翻转，中央球形空腔（0 值）、外壳与多处亮标记点。工具栏另提供
“缺片影像”（删掉第 4 层）与“方向冲突影像”（层轴与行轴重复）用于验证错误提示。
